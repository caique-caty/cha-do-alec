# Imagens dos produtos

Esta pasta contém imagens locais de produtos que vais usar nos cards.

## Como adicionar uma imagem

1. Descarrega a imagem do site da loja
2. Renomeia para algo simples (ex: `monitor.jpg`, `biberao-philips.jpg`)
3. Coloca-a nesta pasta
4. No painel dos pais (`pais.html`), edita o presente
5. No campo "URL da imagem", escreve: `imagens/monitor.jpg`
6. Carrega "Guardar"

## Formatos suportados

JPG, PNG, WebP — recomenda-se que cada imagem tenha menos de 500KB para velocidade de carregamento.
